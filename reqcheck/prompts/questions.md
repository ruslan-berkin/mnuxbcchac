ЗАДАЧА: УТОЧНЯЮЩИЕ ВОПРОСЫ. Для каждого замечания из списка сформулируй один конкретный вопрос аналитику, ответ на который закрывает дефект.

Правила:
- Вопрос самодостаточен: из него понятно, о чём речь, без чтения замечания. Называй сущность, условие или число.
- Вопрос предлагает варианты ответа, если они очевидны («A или B?»), и не содержит ответа внутри.
- Один вопрос на одно замечание. Вопрос задаётся аналитику, а не разработчику.
- Поле finding_id копируй из списка без изменений.

Верни JSON: {"questions": [{"finding_id": "D-001", "question": "..."}]}
