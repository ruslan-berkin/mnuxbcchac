ЗАДАЧА: ПРОВЕРКА НАБОРА ТРЕБОВАНИЙ ЦЕЛИКОМ (29148 п. 5.2.6, IEEE 830 п. 4.3). Используй только эти коды:

<<criteria>>

Что искать (перекрёстные проверки):
- Функциональные требования ↔ критерии приёмки: каждое ли требование покрыто хотя бы одним критерием, не противоречит ли критерий требованию (границы, даты, пороги, исключения), есть ли критерии на граничные случаи, возвраты, повторные события, выключенное состояние.
- Основная часть ↔ дочерняя спецификация / API: совпадают ли названия сервисов и методов, описано ли в API всё, что требует основная часть (в том числе чтение данных), нет ли в API того, чего нет в требованиях.
- Данные ↔ API: совпадают ли поля, типы и единицы измерения (например, разные единицы одной величины), есть ли в данных всё, что нужно требованиям.
- Нефункциональные требования ↔ цели: измеримы ли они (точка отсчёта, перцентиль, способ измерения) и достигают ли заявленной цели.
- UI ↔ API: у каждого элемента интерфейса есть метод API, из которого берётся значение или в который оно отправляется; описаны тексты и поведение ошибок.
- Внутренняя согласованность: требования, которые исключают друг друга, разные формулировки одного и того же правила, разные названия одной сущности.
- Полнота (S-CMP): чего в наборе не хватает до начала разработки и тестирования (обработка ошибок, откат, права, идемпотентность, пустые разделы, тестирование). Каждый пробел оформи отдельным замечанием с критерием S-CMP и вопросом аналитику.
- Трассируемость (S-TRC), валидируемость (S-VAL), ранжирование по важности (S-RNK), модифицируемость (S-MOD, версия, история): только по конкретным признакам в тексте.

Правила вывода:
- findings: замечания с критерием из набора S-*. В requirement_ids перечисли затронутые требования (R-xx), если они есть; пробел набора может быть без requirement_ids.
- Для противоречия давай цитату на каждую из сторон.
- conclusions: по КАЖДОМУ из восьми кодов S-CMP, S-CON, S-FEA, S-CMH, S-VAL, S-RNK, S-MOD, S-TRC дай один вывод в 1–2 предложения: что проверено и какой результат. Если замечаний нет, так и напиши.
